# ADR-04: PostgreSQL Expense Model

**Status:** Approved in Throughline - part of Architecture v1, option B ("Next.js Server Application").

## Decision

Persist user-owned expenses in Supabase PostgreSQL and query monthly category totals from the database.

## Technology / approach

Supabase PostgreSQL with user ownership and grouped queries

## Constraints

- Support expense create, edit, and delete.
- Support month and category filters and monthly category breakdowns.

## Trade-offs

- Database-side summaries reduce application aggregation but require validated query and index choices.
