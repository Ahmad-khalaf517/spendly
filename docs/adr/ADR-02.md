# ADR-02: Supabase Session Authentication

**Status:** Approved in Throughline - part of Architecture v1, option B ("Next.js Server Application").

## Decision

Use Supabase Auth with server-managed session handling for email sign-in and password reset.

## Technology / approach

Supabase Auth with Next.js session integration

## Constraints

- Support email-and-password sign-in and forgotten-password reset.

## Trade-offs

- Centralizes identity with Supabase but requires consistent session handling across server and browser code.
