# ADR-03: User-Scoped Server Access

**Status:** Approved in Throughline - part of Architecture v1, option B ("Next.js Server Application").

## Decision

Run expense reads and mutations through server actions or route handlers using the authenticated user's Supabase session.

## Technology / approach

User-scoped Next.js server actions and route handlers

## Constraints

- A signed-in user must not view or modify another user's expenses.

## Trade-offs

- Centralizes data operations but adds server endpoints that must preserve user authorization.
