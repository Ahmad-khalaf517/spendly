# ADR-05: Server CSV Export

**Status:** Approved in Throughline - part of Architecture v1, option B ("Next.js Server Application").

## Decision

Provide a Next.js route handler that returns the authenticated user's selected month's expenses as CSV.

## Technology / approach

Authenticated Next.js CSV route handler

## Constraints

- Export the selected month's expenses as a downloadable CSV.

## Trade-offs

- Keeps export formatting and row selection on the server but adds a route to secure and maintain.
