# ADR-01: Full-Stack Web Framework

**Status:** Approved in Throughline - part of Architecture v1, option B ("Next.js Server Application").

## Decision

Implement the web interface and backend endpoints in a single Next.js application using React and TypeScript.

## Technology / approach

Next.js server-rendered application

## Constraints

- Web browser access
- Frontend must use React and TypeScript
- First release is planned for six weeks

## Trade-offs

- Provides an integrated application structure but introduces server-rendering and function configuration.
