# Next.js Server Application

_Generated by Throughline (FR-033) - initialization mode: **scaffold**. A Next.js starter was generated from the selected stack - see Getting started below._

A Next.js React and TypeScript application serves the web interface and handles data operations through Vercel server functions, using Supabase Auth and PostgreSQL with user-scoped access.

## Technology stack

| Layer | Choice |
| --- | --- |
| Frontend | Next.js with React and TypeScript |
| Backend | Next.js server actions and route handlers |
| Database | Supabase PostgreSQL |
| Hosting | Vercel and Supabase free tier |
| Repository layout | Single Next.js application repository |

## Getting started

```bash
npm install
cp .env.example .env.local   # then set DATABASE_URL
npm run dev
```

Then open http://localhost:3000/ (health check at `/api/health`). Type-check with `npm run typecheck`. Generate and apply migrations with `npm run db:generate` and `DATABASE_URL=... npm run db:migrate`.

**Not generated** (documentation only): infrastructure and deployment configuration for the chosen hosting.

## Trade-offs considered

- **Delivery deadline:** Next.js provides frontend and server endpoints in one application, but its server-side session and deployment setup must be completed within the six-week first-release deadline.
- **Team skills:** The team has React and TypeScript skills that transfer to Next.js, though the stated skills do not include Next.js server rendering or server actions.
- **Security constraints:** Server-side operations can keep database access out of the browser, while user-scoped Supabase sessions and PostgreSQL row-level security are still needed to meet R-03.
- **Deployment complexity:** Vercel supports Next.js and Supabase is the required database host, but server functions add deployment configuration beyond the Vercel static hosting in the other option.
- **Cost:** The application must remain within the Vercel and Supabase free tiers; server-rendering and function usage must be monitored against those limits.
